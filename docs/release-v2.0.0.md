# v2.0.0 — 分层 agent 运行时

这次不是加功能，是换骨架。从「一个能聊天的脚本」变成按职责分层的运行时。

行为上最大的变化：**它开始自己判断该不该动手、动手之后怎么收尾**，而不是等你催第二遍才真的去干。

---

## 架构

`src` 按「干哪一类事」拆成八层，改一个功能基本只动一个目录：

| 目录 | 放什么 |
|---|---|
| `config/` | 配置解析与工具权限 |
| `chat/` | 对话本体：模型调用、工具循环、连发合并、任务清单、待发内容 |
| `memory/` | 三层记忆、目标、情绪记录、群知识、群画像、群记录 |
| `skills/` | 技能加载、自我能力说明、任务模板 |
| `tasks/` | 工单、Worker、定时任务、巡检、自愈节流、推送台账 |
| `channel/` | QQ 这一侧：发送、媒体、入站附件、触发、撤回、观察 |
| `engage/` | 主动接话、热点吐槽、降噪与静音 |
| `ops/` | 代码同步、备份、用量统计、失败复盘、临时目录 |

配套的还有：

- 配置默认值全部收归 `config/env.js`，散落各处的 `process.env` 读取统一了
- 启动打两行 `[配置]` 摘要，`.env` 只写三行也能看清当前生效了什么
- `pnpm diagnose` 增加依赖自检，缺哪个包直接列出来

## 新增能力

### 对话与理解

- **连发合并**：同一个人 1.2 秒内连着发几句，合成一次理解再回答，不再逐句回三遍
- **空承诺拦截**：只回「我这就去」却没调用工具，会被要求立刻动手；调过工具后的正常总结不会被打断
- **交接摘要式压缩**：上下文快满时写的不再是「聊了些什么」，而是要求保留确切命令、路径、返回值、错误原文，区分已定决策与未决问题，未验证的必须标明
- **超长输出可回读**：工具返回超过 7000 字时，全文落到 `tmp/tool-output/`，上下文里只放摘要 + 路径
- **重复调用复用**：只读工具用完全相同的参数重复调用时，直接返回上次结果，不重复执行

### 记忆

- **群知识沉淀**：每小时把群记录聚合成「本群情况」（谁常来、什么时段、聊什么），每轮注入提示词
- **群成员画像** `read_profile`：不传人参看活跃排行，传名字看单人
- **情绪记忆与回访** `note_situation`：记下「谁在为什么事发愁、卡在哪」，隔几小时主动问一次，一件事只问一次

### 做事

- **任务清单** `todo_write`：三步以上的活先拆步骤，做完一项打一次勾；超过 5 步没更新会提醒
- **`edit_file` 精确改文件**：原文必须唯一匹配，找不到就提示先读一遍再改，比整文件重写安全
- **任务模板**：工单跑成功后自动沉淀「目标 → 工具路子 → 踩过的坑」到 `skills/templates.md`
- **失败复盘**：同一工具连续失败 3 次写进 `skills/pitfalls.md`，之后每轮都看得到

### 开口

- **主动接话**：定时翻群记录找「有人问但没人答」的问题，四道抑制（冷却 / 静默 / 每小时上限 / 同问题不重复）
- **热点吐槽**：到点自己搜当天科技新闻，用群友语气损两句，敏感词黑名单直接丢弃（默认关）
- **选择题** `ask_choice`：编号选项 + 回数字选中
- **群内降噪 + 「安静」指令**：群友一句话就能让它闭嘴，期间只回 @

### 闭环

- **技能按需加载**：技能支持单文件或目录（`SKILL.md` + 元数据），正文超预算只挂摘要，用 `read_skill` 读全文
- **每日备份**：`data/` 和 `skills/` 自动备份到 `backups/`，保留 7 份
- **自愈节流与推送台账**：定时任务挂了会自己查去改，但有次数上限；补跑 / 重试 / 重启补跑三条路都可能重发，发前先查台账
- **撤回**：记下发出去的消息 id，能撤自己发错的那条
- 新命令：`/help` `/config` `/memory list` `/forget`

## 修复

其中几条是会让机器人整体失灵的：

- 模型调用包装函数自己调用自己 → 所有对话栈溢出，只会回「抱歉，我这边暂时无法回答」
- 空承诺拦截用了当前模型不支持的 `tool_choice: required` → 触发即整轮 400
- 空承诺检测只在设过目标时生效 → 普通请求完全不拦
- `calc` 大整数溢出，`123456789 × 987654321` 少了七百多
- 私聊流式接口没开通权限 → 每次长回复先撞一次失败（已默认关闭 + 熔断，首段失败回落普通发送）
- 可选依赖缺失拖垮整个内置工具服务 → 改为按需加载，只让对应工具报错

其余：

- `/reset` 清不干净：任务清单、待选状态、分段暂存、连发批次、情绪记录都还留着
- 上下文压缩后用户消息下标错位，图片降级改到了历史消息上
- 群里发数字选不中选择题
- 长回复超出单条消息被动回复上限时静默丢段
- 超过被动回复窗口的消息仍然硬发
- 只 @ 不说话被静默丢弃
- 超长输入直接拒收，改为截断后照常回答
- 群里记忆命令没有管理员校验，群友能清掉整个群的上下文

## 变更

- 默认值收敛：工具轮数上限 100 → 12、详细日志默认关、上下文窗口按 128K、私聊进度提示 3 条
- 私聊流式默认关闭（需要平台单独开通 `/stream_messages` 权限）
- 依赖换成熟实现：cron 解析、PNG 编码不再手写

## 升级

`.env` 不用改，新增的配置项都有合理默认值。

```bash
cd /qq && git pull --rebase origin main && pm2 restart dafeiyu
```

如果 `package.json` 依赖有变化（这一版没有），记得先 `pnpm install --prod`。
